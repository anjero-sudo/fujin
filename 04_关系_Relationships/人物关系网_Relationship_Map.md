# 人物关系网 / Relationship Map

## 关系设计原则

人物关系必须同时包含至少两层：

- 情感关系
- 利益关系
- 权力关系
- 秘密关系
- 债务关系
- 家庭责任

任何重要关系都不应只有“爱/恨”两个状态。

## 关系字段

每一对核心人物需要记录：

- A如何看B
- B如何看A
- A想从B得到什么
- B想从A得到什么
- 共同秘密
- 利益冲突
- 情感债
- 当前权力高低
- 关系第一次变化
- 关系最严重破裂点
- 是否存在不可逆事件
- 最终关系

## 重点关系

- 男主 ↔ 女主：真爱、婚姻、阶层、责任、幻灭
- 男主 ↔ 白秀珠位：共同成长史、阶层默契、旧情/未完成情感、现实资源
- 女主 ↔ 白秀珠位：竞争、尊重、嫉妒、互相看穿
- 男主 ↔ 大哥位：宠爱、兜底、羞辱、责任、权力
- 女主 ↔ 金母位：善意、接纳、控制、牺牲
- 男主 ↔ 父亲位：自由与继承之间的冲突
- 大哥位 ↔ 大嫂位：婚姻、资产、孩子、体面与背叛

## 核心要求

最终要形成：

> A的选择改变B → B为了自救伤害C → C的反击影响D → 最后重新撞回A。

这才是群像结构，而不是多人平行支线。
