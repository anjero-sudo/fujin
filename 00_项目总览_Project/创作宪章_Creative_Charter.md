# 创作宪章 / Creative Charter

## 一、项目目标

把《金粉世家》的核心悲剧结构转译为当代都市家族群像，并形成能够独立成立的新IP《浮金》（工作名）。

## 二、不可偏离的创作方向

- 不是“换皮翻拍”。
- 不是霸总爽剧。
- 不是传统慢节奏电视剧。
- 不是连续堆反转的低成本狗血合集。
- 是：**细腻群像 + 强人性 + 高戏剧密度 + 现代都市狗血 + 家族兴衰。**

## 三、狗血使用规则

狗血不是目的，是压力测试。

每个重大狗血事件至少要完成以下一项：

1. 暴露一个人物真正的欲望；
2. 迫使人物在两种损失之间做选择；
3. 改变两个人之间的权力关系；
4. 让一个人物跨越自己的底线；
5. 让此前被误解的人物获得新的解释；
6. 让家族利益与私人感情发生不可调和的冲突。

## 四、人物规则

每个核心人物必须具备：

- 表层目标
- 深层缺失
- 最大恐惧
- 隐藏秘密
- 利益来源
- 情感债
- 道德底线
- 越界条件
- 对外形象
- 私下真实状态
- 前期判断
- 中期变化
- 后期代价

禁止只用“好人/坏人/渣男/绿茶/贤妻/恶婆婆”等标签定义角色。

## 五、短剧节奏规则

- 快的是剧情推进，不是单纯剪辑速度。
- 每集必须产生剧情位移或关系位移。
- 开场尽快建立异常、冲突或未解问题。
- 单集应有局部兑现，同时制造新的关系问题。
- 允许安静戏，但安静戏必须让观众处于判断、担忧、期待或重新理解人物的状态。

## 六、AI真人制作规则

剧本阶段即考虑制作：

- 控制无必要的大规模群演场面；
- 重视2—3人高强度对手戏；
- 重要场景尽量复用并形成IP识别；
- 服装、空间、道具承担人物阶层表达；
- 避免只靠复杂动作调度制造戏剧性；
- 用人物表演、视线、停顿、空间关系承担高级感。

## 七、当前优先级

1. 原著内核复核
2. 现代金家家谱
3. 12—15名核心人物
4. 人物两两关系
5. 财富与权力结构
6. 秘密/利益/情感交叉链
7. 总故事大纲
8. 分集
9. 正式剧本
10. AI制作版拆解
