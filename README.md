## 项目定位

本项目不是把《金粉世家》简单换成现代服装，也不是制作传统豪门霸总短剧。

核心方法：

- 保留原著的爱情悲剧、阶层差异、家族兴衰与人物命运内核；
- 将社会结构、财富来源、婚姻关系、职业与生活方式彻底现代化；
- 用现代都市生活中的真实欲望、利益、婚姻、背叛、亲情和阶层冲突制造“狗血”；
- 所有戏剧事件必须服务于人物选择与人性，而不是单纯堆反转；
- 采用正剧人物塑造 + 短剧叙事效率；
- 面向AI真人制作，从剧本阶段控制人物数量、场景复杂度、连续性和可执行性。

## 当前创作原则

1. **原著决定人物命运，现代社会决定事件形式。**
2. **狗血负责把人物逼到墙角，人性决定人物最后怎么选。**
3. **群像不是多人支线，而是人物之间的选择互相改变彼此人生。**
4. 金燕西式男主必须真心爱过冷清秋式女主，不能从一开始就是纯粹渣男。
5. 冷清秋式女主不是“嫁豪门逆袭”模板，她必须拥有独立人格、欲望、虚荣、软弱与代价。
6. 白秀珠式人物不能只是恶毒女二，她应同时具备爱情、利益、尊严、嫉妒与真实能力。
7. 金氏家族的衰败必须与爱情的衰败互相映照。
8. 不依靠单一反派推动全剧；每个主要人物都应站在自己的立场上“有道理”，但理由不能自动取消伤害与责任。
9. 不做廉价追妻火葬场式大团圆，保留悲剧性与余味。
10. 每一集必须产生剧情位移或人物关系位移；强台词要有前提，反击要有兑现。
