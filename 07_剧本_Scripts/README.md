# 剧本 / Scripts

本目录存放正式剧本。

建议每集同时保留两种稿：

- `EPxx_文学剧本_Literary_Script.md`：人物、动作、对白、情绪与场景完整表达；
- `EPxx_AI制作稿_AI_Production_Script.md`：面向AI真人生成拆解，进一步控制镜头、人物连续性、场景与动作复杂度。

剧本标准：

- 对白必须服务人物，不写成信息播报；
- 每场戏都要有明确的关系变化或信息变化；
- 避免所有人物说同一种“编剧腔”；
- 重要情绪允许停顿与留白；
- 狗血事件必须有前因与人物代价；
- 不以强行误会维持剧情；
- 不依赖角色突然降智制造冲突。
