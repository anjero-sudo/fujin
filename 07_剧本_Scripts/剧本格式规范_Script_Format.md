# 《浮金》剧本格式规范 / Script Format

## 单集目标

- 时长：3—5分钟
- 核心场景：1—3个
- 核心事件：1个
- 明确人物关系位移：至少1次
- 开场前10秒必须出现冲突、异常或强问题
- 结尾必须改变观众对下一集的预期

## 正式剧本字段

### 场次标题
`场次 / 内外景 / 地点 / 时间`

例如：

`1. 外景·南湾旧厂房·日`

### 场次信息
- 预计时长
- 出场人物
- 场景目的

### 正文
只写能够被拍出来或演出来的内容：

- 动作
- 表情
- 可见环境
- 对白
- 必要停顿

不写大段人物心理解释。

### 对白原则

1. 人不会把自己真正想法全部说出来。
2. 尽量允许一句话有表面意义和潜台词。
3. 不写“女人，你成功引起了我的注意”式霸总台词。
4. 不用金句替代真实交流。
5. 豪门人物不靠反复报价格证明有钱。
6. 每个人说话方式不同：
   - 程叙：松弛、会开玩笑，但真正难受时反而变简短；
   - 林书禾：准确、克制，不喜欢夸张表达；
   - 宋知岚：信息密度高，很少说废话；
   - 程致远：结果导向，句子短，习惯直接下结论；
   - 程世勋：不大声，但习惯一句话结束讨论；
   - 许曼芝：温和，会给人台阶，也因此很难正面拒绝。

## AI真人制作规则

1. 同一集尽量避免超过5名主要可见人物。
2. 大场面优先使用近景、局部、声音和少量固定人物建立规模感。
3. 动作必须适合当前AI视频能力，减少复杂多人接触与长时间连续调度。
4. 人物识别点必须按角色档案保持一致。
5. 场景中重要道具必须记录连续性。
6. 正式生成前，再由剧本拆成“镜头/Seedance提示词”版本，不在文学剧本里过度写提示词。

## 节奏检验

每一场戏结束时问：

> 这场戏开始前和结束后，有什么不一样？

如果答案只是“人物聊了一会儿”，删除或重写。
