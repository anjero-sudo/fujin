# 《浮金》V1.3｜台词、角色语言与节奏验收

> 配套正文：`07_剧本_Scripts/V1.3_全季强化_Full_Season/`，EP01—EP36。
> 本文件是制作与修订标准，不是另一个故事版本。这里的“声纹”指人物语言习惯，不指实际配音模型、克隆声音或已经测试过的音色。
> 状态：书面正文已完成；4—6分钟是单集目标，实际时长须经试读和动态分镜核尺。未实施观众留存测试。

## 一、台词负责刺中问题，事件负责兑现

本剧的语言强化不是全员轮流说狠话。对手先提出具体要求或判断，人物以事实、反问或拒绝拆穿其中的问题，随后发生可见的关系或行动变化。

核心检查：这句说完，对方还能够完全照原计划往下做吗？如果可以，而且没有新的情感后果，它可能只是装饰性的金句。

例如：EP04纠正错误路线后对方让位、改称林工；EP05男主先支持女主发言，再询问她要不要离席；EP22冒用意见被指出后，更正实际发回原收件人；EP28最终声明不能再声称没有专业分歧；EP32“家庭已同意”的记录被更正；EP33完整材料进入正式核查。反击都不能只剩震惊特写。

## 二、主要角色的语言区分

| 人物 | 语言习惯与反击方式 | 需要保留的缺口 | 禁止的同质化 |
|---|---|---|---|
| 林书禾 | 先说具体事实，再指出谁在偷换概念；被越界时短句直问，不替对方找台阶 | 会动摇、喜欢便利、会哭；不是一开始就能分析清楚全部婚姻问题 | 每场都冷静宣讲独立，不表现舍不得与欲望 |
| 程叙 | 前期玩笑接话、主动示好；中段开始用效率和现实说服人；后段能承认自己的选择 | 能做成有限的事，也会躲、怕、希望妻子比别人好说服 | 突然成为商业天才，或从第一集就演成坏人 |
| 程致远 | 先问金额、期限、结果；急时打断；反击来自长期善后和机会成本 | 对家人有真实关心，承认责任不等于掌握所有人的权利 | 所有狠话都正确，其他人只能接受他的安排 |
| 宋知岚 | 准确、直接，工作上给条件；熟人之间有损人的幽默；私人情绪偶尔刺破专业说法 | 承认喜欢被需要，也承认自己的商业选择 | 永远无私的导师，或偷偷策划所有坏事的女二 |
| 顾晚晴 | 问是谁同意、按哪一项推进；不接受以信任代替解释；必要时公开纠正 | 曾经相信丈夫，也需要时间意识到自己能离开 | 拿一页文件便自动取得所有财产与孩子的控制权 |
| 程庭安 | 玩笑开场，被贬低时停止替大家缓和；要求把账说完整 | 投资有来历、有退出代价，只解决阶段问题 | 隐藏首富、突然拿出能救全公司的现金 |
| 程臻 | 直、快、容易刺人；不满意就追问具体安排 | 承认父亲帮助与自己劳动同时成立，经营决定不能只为赌气 | 一边说独立，一边把员工和经营后果全交给别人 |
| 周岚秋 | 用生活中的具体得失指出偏向；既护女儿，也反问她的执念 | 不替女儿决定离婚，也不羞辱另一位母亲的一生 | 女主永远正确的代言人 |
| 许曼芝 | 好意往往先以安排出现；会反驳，会难过，后来学着停止代谈 | 保留她对自己婚姻选择的认同，不要求她自我否定 | 一句“我懂了”以后所有柔性控制消失 |
| 韩秉文 | 问记录、页码、谁决定；不再接受模糊许诺；短句最重 | 承认自己的真实执行，不寻求删掉全部责任 | 原件万能、当众曝光便自动免责 |
| 程世勋 | 习惯问结果、下安排；被反问以后逐项承认，而非一句全算我的 | 交权之后仍有控制惯性；改变通过停止插手体现 | 一次发言便变成全知、无错的道德导师 |
| 程以宁 | 从镜头外问问题，到坐在桌边说自己的意见 | 有过低估公开传播风险的失误，也能主动不拍 | 只负责偷听、偷拍和替成年人曝光秘密 |

## 三、情绪密度与节拍

以五分钟为工作参考：前15秒让异常已经发生；一分钟内明确本场谁要什么；中段至少有一次有效阻拦、反击或事实增量；后段作出决定；结尾兑现本集冲突并引出后果。该分配不是平台规则，不能机械套秒数。

四分钟版优先删重复说明、同义反问和进出场手续；六分钟版增加有意义的阻力、试探或后果，不增加空走路和重复凝视。不用加速配音把过长对白硬塞进时长。

一集以一个主冲突为中心，支线只在改变该冲突的条件时插入。不是每集都要打脸：甜、喜、能力胜利、地位反转、关系破裂、承担后果应交替，让观众既想看人物赢，也在乎人物失去什么。

正文中的“本集执行”“季终执行”等是给制作人员的备注，不念成旁白。说明法律、财务与专业边界的备注也不是对白时长的一部分。

## 四、删减与保留

可以优先压缩：重复讲同一份消息；进门后寒暄再重新进入已知话题；无信息的倒水、走路、换座位；每句狠话后轮流给所有人反应；人物重复解释观众已经看见的情绪。

应保留：新的证据出现时的辨认；关键决定前真实犹豫；签署、撤回、补发、让位、离开等行动；主角听见刺中自身盲点后短暂改变回应方式。停顿只在观众有明确期待时成立。

举例：EP30门关上，手机显示本轮有条件通过，再回到未发送的通知，已经完成代价对撞。不要追加旁白替观众总结胜利多么苦涩。

## 五、全季反击与高光定位

| 类型 | 集数 | 拍摄落点 |
|---|---|---|
| 专业反击 | EP01、04、09、22 | 依据、具体方案与对方实际改变，不是只拍漂亮的冷脸 |
| 前期恋爱兑现 | EP03、05、07、08 | 双向选择、尊重她回答、真实共同成果，不能提前演出背叛预兆 |
| 男主有限成功 | EP13、17 | 补齐流程、完成职责、争取有限时间；不是凭姓氏取消规则 |
| 被低估者取得决定权 | EP24 | 从被打断到必须认真谈他的条件；保持钱的有限性 |
| 公开拒绝被代言 | EP28、32 | 最终声明和会议记录实际更正，错误表态不能换个渠道继续用 |
| 情绪与价值破裂 | EP23、26、29、30、31 | 允许提高声音、说不周全、掉眼泪；不让所有角色时刻表达满分 |
| 自保与旧权威失效 | EP25、33 | 完整材料实际交付，有人第一次没有跟着父亲去关门谈 |
| 承担与分别 | EP34、35、36 | 交权、善后、成果采用、结束关系；成长不兑换自动复合 |

## 六、AI制作验收

每个对话段先锁定说话者、视线与空间轴线。多人戏可用建立镜头、双人关系镜头及关键单人近景拆解，但要保留真正的递交、阻止、离开和共同工作，避免全剧变成人物轮流念台词。

手机、报告、签署页、付款提示与声明均作为固定道具制作，再做后期合成。不能让模型随意生成关键文字，也不能让道具在正反打之间变位。每个近景只设一个主要情绪变化，不叠加相互冲突的表演要求。

试读时分别记录可发声文本、有效停顿、动作、屏幕阅读和转场的耗时。每集按实际总时长调整，不按汉字数直接宣称已达标。先做EP01现场冲突、EP26信息亲密错位、EP30签字决裂的试片，检验核心表达；这是制作建议，尚未完成试片。

## 七、交付前逐集验收表

- 本集冲突能否在一句话里说清，且不是单纯“某人了解一个道理”？
- 强台词是否回应了具体前提，而非可随意搬给任何人物的励志句？
- 反击以后，行为、关系或可选方案是否改变？
- 对手是否有合理的利益与反应，而非故意降智等待打脸？
- 主角是否有行动结果，配角是否拥有自己的要求与损失？
- 关键对白读起来是否像角色本人，而不是全部出自同一个演讲者？
- 时长是否经实际核尺，专业事项是否经过独立审校？未做的必须标未做。
